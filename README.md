> ## ⚠️ Archived — no longer maintained
>
> This repository is a Liquibase fork/mirror of [Homebrew/homebrew-core](https://github.com/Homebrew/homebrew-core). It previously hosted the `liquibase` and `liquibase-secure` formulae as a staging/build mirror for Liquibase's Homebrew distribution.
>
> **It is no longer needed.** Liquibase's Homebrew artifacts now ship from the **official upstream** Homebrew taps:
>
> * OSS Liquibase — formula in [Homebrew/homebrew-core](https://github.com/Homebrew/homebrew-core/blob/master/Formula/l/liquibase.rb): `brew install liquibase`
> * Liquibase Secure 5.x — cask in [Homebrew/homebrew-cask](https://github.com/Homebrew/homebrew-cask/blob/master/Casks/l/liquibase-secure.rb): `brew install --cask liquibase-secure`
>
> This fork is not kept in sync with upstream and is intentionally excluded from the org-wide GitHub Actions SHA-pinning enforcement (TECHOPS-646). Retained for reference only. Confirmed unneeded by the DevOps team, June 2026.

# Homebrew Core

Core formulae for the Homebrew package manager.

 [Homebrew/discussions (forum)](https://github.com/orgs/Homebrew/discussions)

## How do I install these formulae?

Just `brew install <formula>`. This is the default tap for Homebrew and is installed by default.
